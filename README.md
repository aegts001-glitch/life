# Life

Личное веб-приложение для iPhone: заметки, напоминания, планы, деньги, машина, объекты.

Открыть: https://aegts001-glitch.github.io/life/

Установка на iPhone: откройте ссылку в Safari → «…» → «Поделиться» → «На экран „Домой“» → «Добавить».

Данные хранятся только на телефоне (в браузере). В репозитории лежит лишь код приложения.

## Версия 2.2

- Планы заново: кольцо дня, лента дат, группы по времени суток, лента, важность, метки, подзадачи и повтор. Строка «завтра в 9 …» понимает день и время. Смахните карточку, чтобы завершить или удалить, потяните за ручку, чтобы поменять порядок.
- Движение как в Telegram: инерция и резиновый край, появление списком, крупный заголовок складывается в стеклянную полоску, экраны выезжают пружиной, листы тянутся пальцем, потяните вниз, чтобы обновить. «Уменьшить движение» это выключает.
- Старые планы остаются: к ним добавляются пустые подзадачи и обычная важность, даты и названия не теряются.

## Версия 2.1

- Долги: кто должен мне и кому должен я, сумма, срок, частичные платежи, напоминания и итоги по людям. Смахните карточку, чтобы внести платёж.
- Персонализация: валюта, копейки, формат даты, размер текста, нижняя панель, раскладка главной, блоки «Сегодня», свой акцентный цвет, за сколько предупреждать о делах и долгах.
- Общий вид для iPhone: крупнее текст, плавающая панель вкладок, пружинные переходы и карточки. Системная настройка «Уменьшить движение» выключает анимации.
- Старые записи и резервные копии открываются. Хранилище поднимается до версии 3, ничего не стирается.

## Версия 1.7

- «Сегодня»: общий список планов, напоминаний и сроков по объектам; перенос просроченного плана на сегодня.
- Поиск по включённым разделам с открытием найденной записи.
- Повреждённые данные не перезаписываются пустыми; ошибки сохранения видны на экране.
- Предпросмотр восстановления, локальная копия до импорта и отчёт о недоступных вложениях. Видео по-прежнему сохраняются отдельно.
- Повторы на 29–31 число учитывают короткие месяцы и исходное число.

Проверки: `node core.test.cjs` и `node ui-regression.test.cjs`.
