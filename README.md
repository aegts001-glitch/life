# Life

Личное веб-приложение для iPhone: заметки, напоминания, планы, деньги, машина, объекты.

Открыть: https://aegts001-glitch.github.io/life/

Установка на iPhone: откройте ссылку в Safari → «…» → «Поделиться» → «На экран „Домой“» → «Добавить».

Данные хранятся только на телефоне (в браузере). В репозитории лежит лишь код приложения.

## Версия 1.7

- «Сегодня»: общий список планов, напоминаний и сроков по объектам; перенос просроченного плана на сегодня.
- Поиск по включённым разделам с открытием найденной записи.
- Повреждённые данные не перезаписываются пустыми; ошибки сохранения видны на экране.
- Предпросмотр восстановления, локальная копия до импорта и отчёт о недоступных вложениях. Видео по-прежнему сохраняются отдельно.
- Повторы на 29–31 число учитывают короткие месяцы и исходное число.

Проверки: `node core.test.cjs`.
